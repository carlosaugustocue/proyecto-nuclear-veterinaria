# Sistema Veterinaria - Frontend

Frontend desarrollado con **Vue 3** + **Vuetify 3**.

## 🚀 Inicio Rápido

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev
```

Abrir: `http://localhost:3000`

## 🔌 Backend

Asegúrate que el backend Spring Boot esté corriendo en:
`http://localhost:8080`

## 🎨 Colores

- Primary: #003f70
- Secondary: #4a90e2
- Success: #00bfa5

## 📦 Build

```bash
npm run build
```
